# Shazim Loyihasi

## Tavsif
Shazim - bu turli platformalardan (TikTok, YouTube, Instagram) musiqalarni topish va qidiruv tarixini saqlash uchun mo'ljallangan servis.

## Arxitektura Qarorlari
- **Backend:** Express.js asosidagi API server.
- **Ma'lumotlar bazasi:** PostgreSQL (Drizzle ORM bilan).
- **API Spec:** OpenAPI 3.0 standarti (v1.1.0).
- **Integratsiyalar:** YouTube, TikTok oEmbed API.
- **Frontend:** TailwindCSS bilan bezatilgan React ilovasi.
